# Dialect

**Publisher**: Thorny Games
**Designer**: Kathryn Hymes, Hakan Seyalıoğlu
**Year**: 2018
**System**: Language Creation
**Genre**: language-creation, community, tragedy
**Status**: in-print

## Overview

Dialect, designed by Kathryn Hymes and Hakan Seyalıoğlu in 2018, creates collaborative language-creation game where isolated community develops unique language that dies when community ends, using card prompts to generate words/phrases reflecting community's experiences while three-act structure (isolation → thriving → ending) builds toward inevitable language death, winning ENnie Gold 2019 for Best Writing and establishing language creation as recognized gaming genre, demonstrating how linguistics and communication could be compelling collaborative gameplay through poignant inevitable tragedy of language loss.

**Language Creation**: Actual vocabulary development through play

**Community Focus**: Isolated groups developing shared language

**Inevitable Death**: Language dies when community ends

**Three Acts**: Birth, life, death of language

**Card Prompts**: Generating linguistic development

**ENnie Gold 2019**: Best Writing recognition

**Impact**: Created language gaming genre. Demonstrated linguistic focus viable. Influenced community-tragedy games.

## Core Mechanics

**Isolation Cards**: Defining community's isolation

**Language Generation**: Creating words for community experiences

**Three Acts**: Language emergence, development, death

**Card Prompts**: Triggering word creation

**No Traditional RPG**: Pure collaborative storytelling through linguistics

**Recording**: Documenting language development

## Setting and Themes

**Variable**: Any isolated community (Arctic researchers, generational ship, monastery, refugees, etc.)

**Isolation**: Community cut off developing unique language

**Language Death**: When isolation ends, language dies

**Poignancy**: Creating then losing language

**Themes**: Communication, community, isolation, loss, impermanence

## Cultural Impact

**Language Gaming**: Practically created genre

**ENnie Gold**: Validated linguistic focus

**Educational**: Some linguists/anthropologists using

**Poetic**: Beautiful meditation on language and community

## Reception

Praised for innovation, poignancy, linguistic depth, ENnie-winning writing. Some find experimental—accurate description not criticism. Widely respected.

## Legacy

Established language creation gaming. Sign (2020) followed. Demonstrated linguistics viable gameplay. Influenced community-tragedy designs.
