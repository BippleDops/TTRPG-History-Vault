# Fall of Magic

**Publisher**: Heart of the Deernicorn
**Designer**: Ross Cowman
**Year**: 2015
**System**: Scroll-Map Storytelling
**Genre**: fantasy, journey, melancholic
**Status**: in-print

## Overview

Fall of Magic, designed by Ross Cowman in 2015, provides beautiful 6-foot scroll map showing journey from ordinary world to source of dying magic, with players moving tokens along path choosing locations that prompt storytelling about their companions and magical decline, creating collaborative melancholic fantasy through physical scroll artifact and simple prompt-based narration, demonstrating how beautiful physical components could enhance story games while scroll-map journey structure provided elegant framework for collaborative worldbuilding.

**6-Foot Scroll**: Gorgeous physical map artifact

**Journey Structure**: Path from home to Umbra (magic's source)

**Location Prompts**: Stopping points with storytelling prompts

**Token Movement**: Physical markers along path

**Collaborative**: Building story together

**Melancholic**: Magic dying, end of era

**Beautiful Object**: Game as treasured physical artifact

**Impact**: Scroll-map mechanics influential. Demonstrated physical beauty enhancing gameplay. Journey structure template.

## Core Mechanics

**The Scroll**: Unfurling 6-foot map showing journey path

**Tokens**: Each player moves token choosing locations

**Location Prompts**: "At the Floating Gardens, who shares a secret?" etc.

**Narration**: Players respond to prompts collaboratively

**Companions**: Creating relationships through journey

**Magic Fading**: Theme woven through prompts

**No Dice**: Pure storytelling

**GMless**: Collaborative without facilitator

## Setting

**Fantasy World**: Magic dying, seeking source/answers

**The Journey**: From ordinary to Umbra (magic's origin)

**Locations**: Gardens, ruins, strange places along path

**Melancholic**: Beauty in decay, magic's twilight

**Themes**: Journey, endings, magic fading, companionship, wonder, melancholy

## Cultural Impact

**Physical Artifacts**: Beautiful components as game design element

**Melancholic Gaming**: Poignant tone succeeding

Praised for gorgeous scroll, melancholic beauty, simple elegant storytelling. Became treasured physical game. Some find minimal mechanics limiting but most appreciate simplicity.

## Legacy

Scroll-map influenced journey games. Demonstrated physical beauty importance. Melancholic fantasy viable. Art-object game approach validated.
