# Gender Inclusivity

**Category**: Accessibility
**Era**: 2000s-present (accelerating 2010s-2020s)

## Overview

Gender Inclusivity encompasses games and practices welcoming non-binary, transgender, and gender-diverse players through pronoun options in character creation, inclusive language in text, representation in examples/art, mechanical support for gender diversity (Blue Rose's romantic orientation rules 2005), trans-centered games (Sleepaway 2020), and community norms respecting all genders, with evolution from binary male/female assumptions toward spectrum recognition demonstrating hobby's progress on inclusion while ongoing work remains, showing how design choices and community practices shape who feels welcome.

**Progress**:
- 1970s-1990s: Binary gender assumptions dominant
- 2000s: Some games adding inclusive options (Blue Rose 2005)
- 2010s: Indie games leading inclusion
- 2020s: Mainstream following, trans-centered games succeeding

**Milestones**:
- Blue Rose (2005): First romantic orientation rules
- They/them pronouns in examples increasing
- Character sheet pronoun fields
- Trans designers visible (Jay Dragon, others)
- Trans-centered games (Sleepaway, others)

**Impact**: Hobby becoming more welcoming to gender-diverse players through design and community evolution

## Design Inclusion

### Pronoun Options

**Character Sheets**: Fields for pronouns beyond he/she

**Examples**: Using they/them in rulebooks

**NPCs**: Diverse gender presentation

**No Assumptions**: Not defaulting to binary

### Mechanical Inclusion

**Blue Rose** (2005): Romantic orientation as mechanic (groundbreaking)

**Character Creation**: Gender options beyond male/female

**No Restrictions**: Mechanical benefits not gender-locked

**Representation**: Trans/non-binary NPCs and examples

### Trans-Centered Games

**Sleepaway** (2020): Explicitly trans horror summer camp

**Wanderhome** (2021): Gender-inclusive cozy gaming

**Various Indies**: Centering trans experiences

**Jay Dragon**: Prominent trans designer

## Community Practices

**Pronoun Circles**: Sharing pronouns at Session Zero

**Respect**: Using correct pronouns

**Corrections**: Gracefully handling mistakes

**Inclusive Language**: They/them default for unknown

**Safety**: Protecting trans players from harassment

**Visibility**: Trans gamers and designers increasingly visible

## Historical Evolution

**1970s-1990s**: Binary assumptions, occasional hostility

**2000s**: Some progress (Blue Rose), mostly binary still

**2010s**: Indie games leading, community improving

**2020s**: Mainstream following, trans designers successful, explicit inclusion

## Challenges Remaining

**Hostility**: Some gaming spaces unwelcoming

**Assumptions**: Many games still binary-default

**Representation**: Improving but incomplete

**Safety**: Trans players facing harassment in some communities

**Visibility**: Trans designers/players increasing but minorities

## Progress Made

**Indie Leading**: Story games centering trans experiences

**Mainstream Following**: D&D adding inclusive language

**Designer Visibility**: Trans designers successful (Jay Dragon, others)

**Community Improvement**: Many spaces actively welcoming

**Mechanical Inclusion**: Gender no longer restricting options

**Pronoun Normalization**: Sharing pronouns becoming standard

## Best Practices

**Designers**:
- Pronoun options in character creation
- Inclusive examples
- Diverse representation
- Mechanical gender-neutrality
- Consult trans gamers

**Groups**:
- Pronoun sharing
- Respect pronouns
- Inclusive language
- Safe spaces
- Call out transphobia

**Community**:
- Welcome trans players
- Amplify trans designers
- Address harassment
- Normalize inclusion

## Cultural Impact

**Hobby Improvement**: Gaming becoming more welcoming

**Trans Designers**: Jay Dragon, others achieving success

**Mechanical Progress**: Gender no longer mechanically restricting

**Community Evolution**: Many spaces actively inclusive

**Ongoing Work**: Progress but not complete
