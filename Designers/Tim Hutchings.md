# Tim Hutchings

**Active Years**: 2017-present
**Birth Year**: ~1978
**Nationality**: United Kingdom

Tim Hutchings revolutionized solo journaling RPGs with Thousand Year Old Vampire (2019), using prompted writing and brilliant Memory mechanics (limited slots forcing forgetting of past as centuries accumulate) to create profound meditation on immortality, loss, and inhuman perspective, achieving massive commercial success ($70K Kickstarter, thousands of copies sold) that triggered solo journaling RPG explosion, demonstrating single-player games could achieve mainstream commercial viability while exploring poignant emotional territory through constrained journaling mechanics.

## Major Work: Thousand Year Old Vampire (2019)

Solo journaling vampire game with revolutionary Memory mechanics:

**Memory Constraint**: Only 5-7 Memory slots. Creating new Memory requires erasing or combining old ones, mechanically representing centuries causing forgetting

**Prompt-Driven**: Roll d10 selecting journal prompts from extensive tables

**Character/Resource Tracking**: NPCs who age and die while you persist, possessions and locations across centuries

**Time Progression**: Each prompt advances time (years/decades)

**Beautiful Production**: Hardcover with evocative layout creating treasured physical object

**Commercial Breakthrough**: $70K Kickstarter, strong retail sales unusual for solo game

**Solo Journaling Wave**: TYOV's success triggered explosion of journaling games (Artefact, Apothecaria, Wretched & Alone, hundreds more)

**Impact**: Established solo journaling as major RPG genre. Memory mechanics influenced forgetting/loss designs. Proved solo games commercially viable.

## Design Philosophy

Hutchings emphasizes:

**Solo Gaming Viability**: One-player games as legitimate format

**Journaling as Gameplay**: Prompted writing creating narrative experiences

**Memory Mechanics**: Limited memory representing forgetting

**Emotional Depth**: Profound themes (loss, time, inhumanity) through simple mechanics

**Beautiful Objects**: Games as treasured physical books

**Constraint-Driven**: Limitations (memory slots, prompts) enabling creativity

## Innovations

**Memory Slots**: Limited memory mechanically representing forgetting

**Prompted Journaling**: Structured writing creating narrative progression

**Solo Journaling Genre**: Practically created/established format

**Time-Spanning Play**: Centuries-long character existence

**Loss Mechanics**: Tracking what's forgotten/lost over time
