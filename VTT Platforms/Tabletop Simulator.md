# Tabletop Simulator

**Launched**: 2015
**Developer**: Berserk Games  
**Platform**: Desktop 3D physics simulation (Steam)
**Pricing**: One-time purchase (~$20)

## Overview

Tabletop Simulator (TTS), launched 2015, simulates physical tabletop through 3D physics engine where any component (dice, cards, miniatures, boards) behaves with realistic physics, supporting ANY tabletop game (board games, card games, RPGs) through Steam Workshop's massive mod library, becoming platform for digital tabletop gaming broadly not just RPGs, demonstrating physics-simulation approach appealed to users valuing tactile feel over automation efficiency, though learning curve and performance requirements limited accessibility compared to purpose-built VTTs.

**Physics Simulation**: Objects behave with real physics (dice bounce, cards slide, pieces tip)

**Universal Platform**: ANY tabletop game possible through Workshop

**Steam Workshop**: Massive mod library with thousands of games

**VR Support**: Virtual reality for immersive play

**RPG Secondary**: Primarily board game platform, RPGs possible but not optimized

**Tactile Feel**: Simulating physical table experience

## Features

**Physics Engine**: Realistic object behavior

**Workshop**: Community mods for any game imaginable

**Scripting**: Lua automation possible

**Multiplayer**: Online or hotseat

**VR**: Virtual reality support

**Assets**: Infinite customization through importing

**Flexibility**: Truly universal—not RPG-specific

## Cultural Impact

**Board Game Revolution**: Became primary digital board gaming platform

**RPG Option**: Some use for RPGs despite not being optimized

**Physics Appeal**: Demonstrated tactile simulation niche

**Workshop Ecosystem**: Community content thriving

**Pandemic**: Usage surged during COVID

## Reception

Board gamers love it. RPG users split—some appreciate physics feel, others prefer purpose-built VTTs with automation. Performance and learning curve barriers for casual users.

## For RPGs

**Advantages**: Flexible, physics feel, Workshop has RPG assets

**Disadvantages**: Not optimized for RPGs, no native character sheets/automation, learning curve, performance-intensive

**Use Cases**: Groups valuing physics simulation over efficiency
