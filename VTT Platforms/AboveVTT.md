# AboveVTT

**Launched**: 2020
**Developer**: Community open-source project
**Platform**: Browser extension overlay for D&D Beyond
**Pricing**: Free (open-source)

## Overview

AboveVTT, launched 2020, provides free browser extension adding VTT features (maps, tokens, dice) directly onto D&D Beyond interface, enabling D&D Beyond users to get VTT functionality without separate platform by overlaying tactical tools on official character management, demonstrating clever integration approach where extension enhances existing platform rather than competing, though existing in gray area regarding D&D Beyond's terms of service while serving users wanting combined character sheets and tactical play.

**Browser Extension**: Chrome/Firefox extension

**D&D Beyond Overlay**: Adds VTT to official platform

**Free**: Community open-source project

**Integration**: Character sheets + VTT combined

**Gray Area**: Unofficial modification of D&D Beyond

**Community**: User-driven development

## Features

**Maps and Tokens**: Tactical overlay

**Dice Integration**: Rolling tied to character sheets

**D&D Beyond Data**: Uses official character information

**Free**: No costs, volunteer development
