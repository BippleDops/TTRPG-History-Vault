# Shmeppy

**Launched**: 2018
**Developer**: Danny Brown
**Platform**: Browser-based VTT
**Pricing**: Free (donation supported)

## Overview

Shmeppy, launched 2018, provides radically minimalist battle map tool focusing solely on quick collaborative map drawing and token placement with absolutely zero features beyond essentials, demonstrating extreme minimalism could serve groups wanting just shared tactical space without VTT feature bloat, though limited feature-set restricted audience to those specifically seeking ultra-simple solution.

**Ultra-Minimalist**: Only drawing and tokens

**Real-Time**: Collaborative map creation

**No Features**: Intentionally bare-bones

**Free**: Donation supported

**Niche**: Small dedicated following valuing simplicity

## Features

**Core Only**:
- Draw maps collaboratively
- Place tokens
- Move pieces
- That's it—no dice, character sheets, automation

**Extreme Simplicity**: Advantage and limitation

## Cultural Impact

Demonstrated extreme minimalism niche. Showed some users want absolute simplicity. Part of minimalist VTT movement alongside Owlbear Rodeo.

## Reception

Praised by minimalism fans. Too limited for most users. Serves specific niche well.
