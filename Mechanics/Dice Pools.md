# Dice Pools

**First Appeared**: Shadowrun (1989), Vampire: The Masquerade (1991) prominently
**Category**: Resolution Mechanic / Probability System

## Overview

Dice Pools use multiple dice (typically d6 or d10) where each die is evaluated individually for success (counting how many meet/exceed target number), creating graduated results where more successes mean better outcomes—roll 8 dice needing 5+ on each d6, get 4 successes = moderate success—replacing single-die-vs-DC with multiple-dice-counting-successes, providing bell-curve probability, visual drama of handful of dice, and graduated success levels, becoming signature mechanic for World of Darkness, Shadowrun, and many narrative games.

**Structure**: Roll X dice, count successes (dice meeting/exceeding target number), more successes = better outcome

**Visual Drama**: Handful of dice rattling creates tactile excitement

**Bell Curve**: More consistent results than single d20

**Graduated Success**: 1 success vs. 5 successes provides nuanced outcomes

**Impact**: Became defining mechanic for 1990s-2000s games, influenced narrative gaming dice systems

## Types of Dice Pools

**World of Darkness/Storyteller**:
- Roll dice = stat + skill
- Target number (usually 7+ on d10)
- Count successes
- 1 success = barely, 5+ = excellent

**Shadowrun**:
- Roll dice = stat + skill  
- Target number varies by difficulty
- Count successes (meeting/exceeding TN)
- Compared to threshold

**Burning Wheel**:
- Roll dice = skill level
- Count 4+ on d6 as successes
- Need X successes to overcome obstacle

**PbtA Variants**:
- Some PbtA games use d6 pools
- Count 4-6 as successes

## Design Philosophy

**Graduated Results**: More nuanced than binary success/failure

**Probability Control**: Bell curves vs. linear randomness

**Tactile**: Physical handful of dice engaging

**Visual**: Seeing results immediately on table

**Scalability**: Works for minor actions (3 dice) to epic (20+ dice)

## Reception

**Praise**: Graduated results, tactile fun, probability curves, visual drama

**Criticism**: Arithmetic (counting successes), requires many dice, variable target numbers confusing

## Legacy

Defined 1990s-2000s gaming. Influenced narrative game dice usage. Continues in World of Darkness, Shadowrun, and derivatives.
