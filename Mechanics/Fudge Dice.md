# Fudge Dice

**First Appeared**: Fudge (1995), popularized by [[FATE]] (2003)
**Designers**: Steffan O'Sullivan (Fudge), Fred Hicks & Rob Donoghue (FATE)
**Category**: Dice Mechanic / Special Dice

## Overview

Fudge Dice (dF) are six-sided dice marked with + (plus), - (minus), and blank sides (two of each), rolled in sets of four (4dF) producing results from -4 to +4 with strong central tendency toward 0 (+/-1 most common), creating bell-curve probability around character's skill rating, popularized by FATE Core making them signature special dice recognizable in gaming, demonstrating how custom dice could serve specific probability needs while creating tactile identity for game system.

**Sides**: + (plus one), - (minus one), blank (zero)—two of each

**Standard Roll**: 4dF (four Fudge dice)

**Results**: -4 to +4, centered on 0

**Add to Rating**: Result modifies skill rating (Fair +2 skill: roll +1 = Good +3 result)

**Bell Curve**: Results cluster around 0 (unmodified skill)

**FATE Signature**: Became iconic for system

## Mechanics

**Rolling**: Roll 4dF, count +, -, blanks

**Calculate**: +1 per plus, -1 per minus, 0 per blank

**Examples**:
- [+][+][ ][-] = +1
- [+][-][-][ ] = -1
- [+][+][+][+] = +4 (maximum)
- [-][-][-][-] = -4 (minimum)

**Add to Skill**: Result modifies character's skill rating

**Opposed Rolls**: Both roll 4dF, higher total wins

## Probability

**Central Tendency**: Results cluster around 0
- 0: 23.46% (most likely)
- +1 or -1: ~38% each direction
- +2 or -2: ~12% each
- +3 or -3: ~4.9% each
- +4 or -4: ~1.2% each (rare extremes)

**Bell Curve**: Competent characters usually succeed at appropriate-difficulty tasks

## Cultural Impact

**FATE Identity**: Fudge Dice became FATE's signature element

**Special Dice**: Demonstrated custom dice could define games

**Bell Curve Gaming**: Influenced probability discussions

**Mainstream Awareness**: FATE's popularity made Fudge Dice recognizable

## Reception

**Praise**: Elegant probability, FATE association, bell curve consistency

**Criticism**: Requires special dice (barrier), some prefer standard dice, math overhead for non-enthusiasts

## Alternatives

**Standard d6**: Can simulate with regular d6 (1-2 = minus, 3-4 = blank, 5-6 = plus)

**Digital**: Apps and VTTs handle easily
